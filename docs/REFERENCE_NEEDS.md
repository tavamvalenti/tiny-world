# Reference needs: Las Vegas & London

What would make each map more accurate, roughly in order of impact. Anything not supplied is built from
established geography (street order, hotel order, river course, landmark positions) and well-known architecture.
Nothing important is invented where real geography exists; distances are compressed to fit a playable map
(the order, sides of the street, intersections and relative sizes are kept).

## What was used for this build

No new reference files were supplied, so both maps use established geography: the Strip's real resort order,
sides of the street and cross streets, and the Thames' real course, bridge order and landmark positions.
Architecture follows the landmarks' well-known shapes and colours. Supplying any of the items above will
let the footprints, heights and façades be tightened further.
